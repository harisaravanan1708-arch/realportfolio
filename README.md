## 🚀 Activating GitHub Pages
1. Go to this repository on GitHub: [https://github.com/harisaravanan1708-arch/realportfolio](https://github.com/harisaravanan1708-arch/realportfolio)
2. Click **Settings** (top navigation tab)
3. In the left sidebar, click **Pages**
4. Under **Branch**, select `main` (or `master`) and directory `/ (root)`
5. Click **Save** — GitHub will deploy your site in ~60 seconds!
